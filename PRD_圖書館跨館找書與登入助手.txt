產品需求文件（PRD）
產品名稱：書路 Bookway－圖書館跨館找書與登入助手
版本：初稿 v0.1
日期：2026-10-30
狀態：需求探索完成初步範圍，待資料來源與技術可行性確認

============================================================
1. 產品概述
============================================================

1.1 產品願景
協助民眾更容易找到想讀的書，並了解不同圖書館的登入方式、借閱資格與申辦流程。使用者輸入書名、作者、ISBN 或關鍵字後，盡可能整合公共圖書館與大學圖書館的館藏資訊，提供可理解、可追溯的查詢結果與官方辦理入口。

1.2 問題陳述
- 使用者常忘記各家圖書館帳號登入網址、帳號格式及密碼重設位置。
- 各公共與大學圖書館的借閱證、校外人士及電子書資格規則不一致。
- 使用者在某館借過、無法續借或遇到已借出時，不容易快速知道其他館是否有館藏。
- 各館目錄與電子書平台分散，館藏狀態及登入方法不易比較。

1.3 產品目標
- 提供跨館書目搜尋入口，降低逐館搜尋成本。
- 清楚呈現實體書、電子書及可借狀態（僅限資料來源確實提供時）。
- 對每個館別提供登入方式、借閱資格、申辦／重設密碼官方入口。
- 免註冊、免登入即可使用主要查詢功能。
- 不收集或保存圖書館密碼。
- 允許使用者在本機記錄常用館的登入網址、帳號格式及個人提示，並可匯出／匯入備份。

1.4 非目標（第一階段）
- 不代替使用者登入圖書館帳戶、借書、續借、預約或支付費用。
- 不保證涵蓋全台所有館藏；實際範圍取決於可取得、可授權及可維護的資料來源。
- 不保存使用者密碼、身分證號、借閱紀錄、證件影像或讀者個資。
- 不保證各館即時可借狀態；未取得即時介接時必須明確標示資料時間與來源。

============================================================
2. 目標使用者與情境
============================================================

2.1 目標使用者
- 一般讀者：想知道某書在附近或不同圖書館是否有館藏。
- 大專院校學生：在所屬學校借閱或續借受限，尋找其他館的館藏與館際合作方法。
- 公共圖書館讀者：需要整理不同縣市借閱證與電子書登入方式。
- 不熟悉數位服務的讀者：需要簡明的步驟、資格說明及官方連結。

2.2 主要使用情境
A. 跨館找書：輸入任意字詞，列出書名、作者、出版資訊等欄位中包含該詞的匹配書目，再查看持有館、館藏地、資料類型與狀態。
B. 找可借替代館：目前所屬圖書館無法續借或書籍已借出，使用者查詢其他館是否有相同版本或其他版本。
C. 了解登入方式：從搜尋結果點選某圖書館，查看登入帳號類型、借閱資格、辦證方式、密碼重設入口及官方來源。
D. 記住常用館：使用者本機儲存登入網址、帳號格式和個人提示，不儲存密碼。
E. 換裝置備份：匯出設定檔並在另一裝置匯入。

============================================================
3. 功能需求
============================================================

3.1 跨館書目搜尋（核心功能）
- 搜尋欄接受任意字詞，不限示範書名或預設熱門書。
- 支援書名、作者、ISBN、主題／關鍵字等欄位；資料源有提供時支援繁簡、異體字或拼音等查找方式。
- 搜尋結果應列出所有資料來源回傳且符合查詢條件的書目；不得以少量手動示範資料冒充全台完整結果。
- 提供分頁或漸進載入，顯示匹配筆數或「至少找到」等準確說明。
- 對同書不同版本應盡量分組，但保留版本、出版年、ISBN、語言、格式等差異。
- 空白查詢應提示輸入詞，不應回傳全部資料。
- 無結果時提供查詢建議（例如移除標點、改用作者或 ISBN）及外部聯合目錄入口。
- 搜尋文字需安全呈現，防止 HTML 注入。

3.2 搜尋結果／館藏資訊
每筆書目應在資料可用時顯示：
- 書名、作者、出版者、出版年、ISBN、版本、封面（若合法可用）。
- 館別及館藏地／分館。
- 資料類型：實體書、電子書或其他。
- 館藏狀態：可借、已借出、可預約、館內閱覽、電子資源可使用、狀態未知等。
- 資料來源、查詢時間或最後同步時間。
- 官方館藏目錄連結及必要時的外部全文／電子書平台入口。
- 狀態未知或資料過期時，不得以「可借」呈現；需顯示「請至館方確認」。

3.3 篩選與排序
- 依實體書／電子書篩選。
- 依公共圖書館／大學圖書館篩選。
- 依縣市／地區篩選（列為建議功能，優先度待確認）。
- 依可借狀態篩選（僅適用於來源提供館藏狀態的結果）。
- 支援可借優先、館名、書目相關度等排序；排序依資料實際能力提供。

3.4 圖書館登入攻略
每館資料需包含：
- 正式館名、機構類型、縣市／地區。
- 官方圖書館首頁、館藏查詢、讀者登入、辦證及忘記密碼連結（有獨立頁面時分別記錄）。
- 帳號類型：借閱證號、身分證號、校務帳號、電子郵件等；僅描述格式，不存實際帳號。
- 申請資格與需備文件。
- 校外人士可否入館、可否外借、是否可使用電子資源，三者分開說明。
- 電子書平台名稱及其登入限制（如有官方資料）。
- 密碼重設方式的官方說明連結；不抄錄或儲存個人密碼。
- 官方資料來源、最後查核日期、資料負責者或維護狀態。
- 資格尚未核實時必須明確標示「請以館方規定確認」，不可推定可借。

3.5 我的圖書館（免登入、本機資料）
- 使用者可新增、編輯、刪除常用館。
- 儲存範圍限登入網址、帳號格式／提示、個人提示；明確禁止密碼、身分證號等敏感資料。
- 第一階段資料只存目前裝置瀏覽器的本機儲存空間，不上傳伺服器。
- 清除瀏覽器資料或更換裝置可能遺失，需由使用者主動匯出備份。
- 若本機儲存失敗，需提示使用者並避免誤稱已保存。

3.6 匯出／匯入備份
- 匯出為 JSON 檔，僅含使用者的常用館設定，不包含密碼或搜尋紀錄。
- 匯入前驗證檔案格式及欄位，提供錯誤提示。
- 匯入前說明會新增、合併或取代現有資料；第一版預設取代時須有明確確認。
- 對匯入內容進行字數、URL 格式及資料型別檢查。
- 提示備份檔可能包含個人提示，請妥善保管。

3.7 圖書館目錄
- 提供公共與大學圖書館入口清單及官方連結。
- 清單範圍需可維護；不得因只展示部分館而宣稱已涵蓋全台。
- 之後可依政府公開資料更新公共圖書館基本資訊，再逐館補齊辦證及登入資訊。

============================================================
4. 資料來源與整合策略
============================================================

4.1 初步候選來源
- NBINet 全國圖書書目資訊網：含國家圖書館及合作館提供的書目／館藏資料；官方說明其資料不涵蓋所有圖書館，須呈現涵蓋範圍限制。
- MetaCat+：臺大建置的即時跨館查詢服務，資料主要涵蓋參與的大學圖書館；需確認可否合法、穩定介接。
- 公共圖書館各縣市聯合目錄、公共圖書館共用資源平台及各館自有 OPAC。
- 電子書平台（如 HyRead 等）：先確認公開 API、授權及使用限制；不得以繞過驗證、反爬或未授權爬取作為正式方案。
- 政府開放資料：可取得公共圖書館基本資料（名稱、地址、網址等），但不等同即時書目 API。

4.2 介接原則
- 優先選擇官方 API、正式資料交換或書面授權。
- 未取得介接授權時，提供聯合目錄／館方官方搜尋連結，不冒稱自有即時查詢。
- 每筆資料保留來源及更新時間，依來源使用條款限制快取與再散布。
- 將書目資料與可借狀態分開建模；書目存在不代表有館藏，館藏存在不代表目前可借。
- 建立資料來源狀態監控、錯誤回報及人工更新流程。

4.3 覆蓋範圍聲明
「全台所有圖書館」是產品願景，不是第一版可預設保證的事實。正式對外宣稱的覆蓋率，必須根據簽約／可用資料源的館別名單與最新同步結果計算並公開。

============================================================
5. 非功能需求
============================================================

5.1 資安與隱私
- 不收集圖書館密碼，不做代理登入。
- 個人設定預設本機保存；若未來提供帳戶同步，須另行進行威脅建模、加密設計與使用者同意流程。
- 全站 HTTPS；依最小化原則收集必要的匿名使用統計。
- 搜尋字詞不記名保存；若需分析搜尋品質，須匿名化並在隱私政策中說明。
- 匯入匯出檔案視為使用者可能包含個人提示的資料。

5.2 可用性與無障礙
- 響應式支援桌機、平板及手機。
- 支援鍵盤操作、清楚焦點、標籤、螢幕閱讀器狀態公告及足夠色彩對比。
- 以繁體中文為預設語言；預留英文介面可能性。
- 重要狀態不得只用顏色表示。

5.3 效能與可靠性（目標值待技術評估）
- 搜尋結果首屏在一般網路下盡量於 3 秒內呈現。
- 多資料源可採平行查詢、逾時隔離及部分結果先行展示。
- 單一來源故障時仍顯示其餘來源結果，並標示來源異常。
- 避免重複結果，並可追蹤每筆資料來源。

============================================================
6. 使用流程
============================================================

6.1 找書流程
首頁 → 輸入任意字詞／書名／作者／ISBN → 搜尋 → 檢視所有可取得的匹配書目 → 篩選實體／電子、公共／大學、地區 → 展開館藏地及狀態 → 查看登入資格 → 前往官方館藏／申辦頁。

6.2 登入攻略流程
圖書館總覽或搜尋結果 → 選擇圖書館 → 查看帳號類型與登入網址 → 查看辦證資格／電子資源資格 → 點選官方申請或忘記密碼連結。

6.3 常用館備份流程
我的圖書館 → 新增登入網址與非敏感提示 → 儲存在本機 → 匯出備份 → 在新裝置匯入並確認取代／合併。

============================================================
7. 驗收標準（第一版）
============================================================

- 使用者輸入任意查詢字詞後，系統會查詢已整合資料源，而不是只在手動樣本中搜尋。
- 結果列出所有資料源回傳且匹配的書目，清楚標示搜尋範圍及資料來源；資料源未涵蓋的圖書館不被宣稱已查到。
- 可區別實體書、電子書及其他資料類型。
- 有即時狀態的來源可顯示狀態與更新時間；沒有狀態的來源顯示未知或引導前往館方確認。
- 每個館藏結果可查看登入方式、讀者類別資格、校外人士借閱限制及官方來源。
- 每館資料有最後查核日期；未核實資料有明確警語。
- 可新增、編輯、刪除本機常用館設定；重新載入後資料仍保留。
- 匯出／匯入可正常往返，格式錯誤時安全拒絕並提示。
- 全流程不需要網站帳戶，也不向網站輸入或保存圖書館密碼。
- 320px 手機寬度下主要功能可操作，不產生不必要水平溢位。

============================================================
8. 風險、依賴與未決事項
============================================================

- 各館書目與流通資料系統不同，未必提供公開 API；即時可借狀態可能需合作、授權及經費。
- 聯合目錄的合作館範圍有限，不等於全台所有館。
- 電子書授權常以讀者所在地、持有借閱證、平台採購及同時使用名額為條件；不能只憑書目判斷可閱讀。
- 校外人士資格可能因學期、名額、年齡、校友身分、費用與保證金而改變，必須設置查核日期與維護責任。
- 需確認是否先做「官方目錄整合搜尋」或只提供跨站跳轉的 MVP。
- 需確認第一版優先地區、常用館別，以及是否優先接大學館或公共圖書館。
- 需確認是否在搜尋結果顯示距離排序；需取得定位同意或提供手動縣市選擇。
- 需確認維護登入攻略的負責者、更新週期與使用者回報管道。

============================================================
9. 建議開發階段
============================================================

階段 0：可行性與來源盤點
- 建立公共圖書館與大專校院名錄。
- 向 NBINet、MetaCat+、公共圖書館平台及電子書平台確認介接方式、授權與使用條款。
- 建立官方登入／辦證／校外資格資料表及查核流程。

階段 1：MVP（不宣稱全台即時）
- 搜尋框與已取得授權的書目來源整合。
- 明確呈現來源、館別涵蓋範圍、狀態時間與外連官方頁面。
- 建立常見圖書館登入攻略資料庫。
- 本機常用館設定及 JSON 備份／還原。

階段 2：擴大館別與狀態
- 加入更多公共／大學館 API 或合作資料源。
- 在可用且授權許可的來源中同步流通狀態。
- 加入縣市、距離、格式與資格篩選。

階段 3：服務化
- 建立館方合作管理、資料品質監控、內容審核及更新提醒。
- 視需求評估使用者帳戶同步；仍不得保存圖書館密碼。
