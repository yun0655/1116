Google 登入尚待設定

需先建立 Firebase 專案並啟用 Google 登入供應商。
Firebase 尚未設定。建立專案、註冊 Web App，並將 Firebase 設定值填入網站後才能登入。
  1. 在 Firebase Console 建立專案並新增 Web App。
  2. Authentication → Sign-in method → 啟用 Google。
  3. Authentication → Settings → Authorized domains，加入 GitHub Pages 網域。
  4. 將 Web App 的 Firebase 設定值填入網站程式碼。
Google 登入只負責驗證身分；目前不會把使用者的圖書館設定同步到雲端，也不會收集圖書館密碼。
