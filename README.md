# 書路 Bookway 圖書館跨館找書與登入助手

本儲存庫包含網站前端原型、產品需求文件（PRD）及圖書館登入／借閱資格整理。

## 檔案
- `index.html`：可操作的單頁網站原型。館藏查詢結果目前為示範資料，不是全台即時館藏 API。
- `library-access-guide.md`：代表性公共與大學圖書館的登入方式、資格與官方來源。
- `PRD_圖書館跨館找書與登入助手.docx`：Word 格式產品需求文件。
- `PRD_圖書館跨館找書與登入助手.txt`：純文字產品需求文件。

## 開啟原型
直接以瀏覽器開啟 `index.html`。正式上線前仍需確認圖書館資料來源介接與授權。
